# AurOEBay — mises à jour

Ce dépôt contient seulement la dernière version d’AurOEBay à installer et les scripts de mise à jour.

Mac (Terminal) :

    curl -fsSL https://raw.githubusercontent.com/ImpressionMinute/auroebay-maj/main/maj-mac.sh | bash

Windows (PowerShell) :

    powershell -ExecutionPolicy Bypass -c "[Net.ServicePointManager]::SecurityProtocol=3072;irm https://raw.githubusercontent.com/ImpressionMinute/auroebay-maj/main/maj-windows.ps1|iex"

Tes données restent dans Chrome. Site : https://auroebay.netlify.app
